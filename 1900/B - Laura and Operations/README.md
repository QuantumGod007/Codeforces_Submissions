After that, she has to write another digit $$$2$$$, so at the end of the operation, the board will look like $$$1$$$, $$$1$$$, $$$2$$$, $$$3$$$, $$$2$$$.</p><p>Nemanja asked her whether it was possible for only digits of one type to remain written on the board after some operations.
