It is allowed that both of this blocks are absent.</p><p>For example, the following three arrays are unimodal: <span class="tex-span">[5, 7, 11, 11, 2, 1]</span>, <span class="tex-span">[4, 4, 2]</span>, <span class="tex-span">[7]</span>, but the following three are not unimodal: <span class="tex-span">[5, 5, 6, 6, 1]</span>, <span class="tex-span">[1, 2, 1, 2]</span>, <span class="tex-span">[4, 5, 5, 6]</span>.</p><p>Write a program that checks if an array is unimodal.</p></div><div class="input-specification"><div class="section-title">Input</div><p>The first line contains integer <span class="tex-span"><i>n</i></span> (<span class="tex-span">1 ≤ <i>n</i> ≤ 100</span>) — the number of elements in the array.</p><p>The second line contains <span class="tex-span"><i>n</i></span> integers <span class="tex-span"><i>a</i><sub class="lower-index">1</sub>, <i>a</i><sub class="lower-index">2</sub>, ..., <i>a</i><sub class="lower-index"><i>n</i></sub></span> (<span class="tex-span">1 ≤ <i>a</i><sub class="lower-index"><i>i</i></sub> ≤ 1 000</span>) — the elements of the array.</p></div><div class="output-specification"><div class="section-title">Output</div><p>Print "<span class="tex-font-style-tt">YES</span>" if the given array is unimodal.
